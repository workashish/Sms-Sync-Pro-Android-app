# APK

sms-sync-pro.apk is the verified SMS Sync Pro 2.2 release, Android versionCode 4. It uses the new persistent signing key documented in the workspace's protected signing folder. It cannot update a differently signed original Google AI Studio build.

The old v2.0 build2 file was an incomplete ZIP rejected by Android and has been removed. For future releases, prefer GitHub Releases and reuse the same signing key while increasing versionCode.
